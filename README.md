# StudyFlow – AI-Powered Study Planner

## About the Project
StudyFlow is a web application designed to help students organize their academic tasks, manage deadlines, and track study progress.

The application was developed using AI-assisted coding (Vibe Coding) as part of Mandatory Assignment 3 in Introduction to AI at OsloMet.

## Features
- Add study tasks with subjects and deadlines.
- Mark tasks as completed.
- Automatically calculate completion percentage.
- Delete tasks.
- Save tasks locally in the browser using localStorage.

## Technologies
- HTML
- CSS
- JavaScript
- ChatGPT for AI-assisted development

## Development and Testing
ChatGPT was used to generate the initial application code and assist with development and testing.

The application was tested in Safari by adding tasks, marking them as completed, deleting tasks, and refreshing the browser to verify that saved tasks were preserved.
